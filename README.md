## Description

This Flask and MySQL application supports campus facility maintenance workflows. It stores and presents maintenance requests and their relationships to users, buildings, rooms, categories, priorities, technicians, assignments, work logs, materials, status history, and feedback. The application also provides dashboard summaries and operational reports.

## Technology Stack

- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript
- Jinja2
- mysql-connector-python

## Database

The database is named `campus_maintenance`. Its 13 tables are:

- `buildings`
- `rooms`
- `users`
- `categories`
- `priorities`
- `technicians`
- `maintenance_requests`
- `assignments`
- `work_logs`
- `materials`
- `material_usage`
- `status_history`
- `feedback`

The live schema also contains a `pending_requests` view. The published schema export includes that view. No live row data or personal contact details are included in the repository.

## Features

- Dashboard totals by request status, technician count, average feedback rating, and recent requests.
- Request listing with text search and status, category, and priority filters.
- Request creation using database-backed reporter, room, category, and priority choices; request numbers are generated by the application.
- Request detail pages showing related assignments, status history, work logs, material usage, and feedback.
- Technician listing and assignment.
- Request status updates with application-enforced workflow transitions and closure details.
- Work-log and material-usage entry.
- Feedback submission for completed or closed requests.
- Reports for pending and aging requests, technician workload, building request counts, material usage/cost, feedback, and assignment response times.

## Installation / Setup

### 1. Clone the repository

```bash
git clone https://github.com/pranavv-tech/DBMS-Course-Project.git
cd DBMS-Course-Project
```

### 2. Create and activate a Python virtual environment

Windows PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

macOS/Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install application requirements

```bash
pip install -r application/requirements.txt
```

### 4. Configure local environment variables

Copy `.env.example` to `application/.env`, then edit `application/.env` with your local MySQL username, password, host, and Flask secret key. Never commit that local `.env` file.

Windows PowerShell:

```powershell
Copy-Item .env.example application\.env
```

macOS/Linux:

```bash
cp .env.example application/.env
```

Set `DB_NAME=campus_maintenance`. `DB_PASSWORD` in `.env.example` is a placeholder and must be replaced locally.

### 5. Create/import the MySQL database

For a **new, empty MySQL installation**, import the schema:

```bash
mysql -u root -p < database/schema.sql
```

`database/schema.sql` defines the tables and the `pending_requests` view, but contains no sample rows. The application needs valid lookup records (including users, rooms, categories, priorities, and technicians) in the database to exercise its workflows.

**Do not import this schema over an existing `campus_maintenance` database.** It is an exported structure reference, not a migration or reset script. The live project data is intentionally not distributed; `database/sample_data.sql` documents this.

### 6. Run the Flask application

From the repository root:

```bash
python application/app.py
```

### 7. Open the application

Visit [http://127.0.0.1:5000](http://127.0.0.1:5000).
